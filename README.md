# 꿈꾸는 키친 통합 판매채널 관리

여러 온라인 판매채널의 상품·옵션 품절 및 판매재개 업무 흐름을 한곳에서 확인하기 위한 사내용 웹앱 초기 버전입니다.

## 현재 버전

- Mock 상품과 옵션만 사용합니다.
- 실제 이카운트 또는 판매채널 API를 호출하지 않습니다.
- 실행한 상태와 작업 이력은 현재 브라우저 세션에서만 유지됩니다.
- 새로고침하면 초기 Mock 데이터로 돌아갑니다.

## 확정된 Mock 규칙

- 네이버 스마트스토어
  - 품절: 재고수량 0
  - 판매재개: 재고수량 999
- 오늘의집
  - 품절: 재고상태 `품절`
  - 판매재개: 재고상태 `판매중`
- 카페24
  - 제어 방식 미확정으로 `연동 준비중`과 `미실행`으로 표시
- 사방넷 연동 채널
  - 실제 전파 방식 검증 전이므로 Mock 결과만 표시

## 로컬 실행

```bash
pnpm install
pnpm dev
```

## 검증

```bash
pnpm test
pnpm build
```

## Netlify

저장소 루트의 `netlify.toml`에 다음 설정이 포함되어 있습니다.

- 빌드 명령: `pnpm build`
- 배포 폴더: `dist`
- Node.js: 22

GitHub 저장소를 Netlify에 연결하면 위 설정으로 자동 빌드할 수 있습니다. 비밀번호, API 키와 인증정보는 저장소에 기록하지 않습니다.

## 이후 업그레이드 대상

카페24 제어 방식, 사방넷 전파 범위, 실제 네이버·오늘의집 API, 인증과 권한, 영구 작업 이력은 사용자 확인과 기술 검증 후 별도로 추가합니다.
